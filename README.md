# WWE Universe Ranking Manager 2.0

Aplicación web local sin backend para administrar un universo de lucha libre con:

- Gestión de luchadores y tag teams.
- Ranking por divisiones (RAW / SMACKDOWN).
- Campeones por división con días acumulados de reinado.
- Registro manual de resultados con sistema de puntos dinámico.
- Generación de carteleras semanales y PPV.
- Soft Draft manual.
- Historial de shows.
- Persistencia total en `localStorage`.

## Uso

1. Abre `index.html` en tu navegador (sin internet).
2. Crea luchadores en **Gestión de Luchadores**.
3. Asigna campeones por división.
4. Revisa rankings y genera carteleras.
5. Registra combates para actualizar puntos y estadísticas.

## Tecnologías

- HTML
- CSS
- JavaScript puro (sin frameworks)
