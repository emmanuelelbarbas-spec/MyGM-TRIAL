# MyGM-TRIAL - WWE Universe Ranking Manager 2.0

Aplicación web local (sin backend) para administrar rankings, campeones, combates y carteleras de RAW y SmackDown.

## Uso
1. Abrí `index.html` en cualquier navegador.
2. La app guarda automáticamente en `localStorage`.
3. Podés gestionar luchadores, rankings, shows semanales, PPV e historial.

## Stack
- HTML
- CSS
- JavaScript puro
- `localStorage` para persistencia
