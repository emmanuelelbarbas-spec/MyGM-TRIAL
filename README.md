# MyGM-TRIAL

Aplicación web local para gestionar un modo Universo WWE usando solo **HTML, CSS y JavaScript**.

## Uso
1. Abre `index.html` directamente en tu navegador.
2. Todos los datos se guardan automáticamente en `localStorage`.
3. No requiere internet ni backend.

## Paneles incluidos
- Estado del Universo
- Gestión de Luchadores
- Rankings
- Registrar Combate
- Carteleras
- Listado General
- Historial de Shows
